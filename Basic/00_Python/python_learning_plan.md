## 📖 每日详细学习内容

### 🔴 Day 1: 环境安装与基础语法
- **今日目标**：配置好 Python 环境，理解变量的概念，掌握基本输入输出和算术运算。
- **核心知识点**：
  1. **环境配置**：验证 Python 安装（命令行运行 `python --version`），安装 VS Code 并安装 Python 插件。
  2. **变量与命名规范**：使用下划线命名法（如 `user_name`），无需声明类型。
  3. **基础数据类型**：整型 (`int`)、浮点型 (`float`)、字符串 (`str`)、布尔值 (`bool`)。
  4. **类型转换**：`int()`, `float()`, `str()`, `bool()`。
  5. **基本输入输出**：`print()` 与 `input()`。
  6. **格式化输出**：使用现代的 **f-string**（例如：`f"Hello, {name}"`）。
- **实战练习**：
  - **任务 1：温度转换器**：接收用户输入的摄氏温度，计算并输出华氏温度（公式：$F = C \times 1.8 + 32$）。
  - **任务 2：个人信息生成器**：通过 `input` 收集用户的姓名、年龄、身高，然后用 f-string 格式化输出一段完整的自我介绍。

---

### 🔴 Day 2: 控制流与序列结构
- **今日目标**：掌握条件判断和循环结构，理解并灵活运用 Python 的序列类型（列表和元组）。
- **核心知识点**：
  1. **条件语句**：`if`, `elif`, `else` 结构，注意 Python 的缩进规则。
  2. **循环结构**：
     - `while` 循环：基于条件的循环。
     - `for` 循环：配合 `range()` 或遍历序列。
     - `break` 与 `continue` 的区别。
  3. **列表 (List)**：
     - 创建与索引/切片（支持负索引，如 `list[-1]`）。
     - 常用方法：`append()`, `insert()`, `pop()`, `remove()`, `sort()`, `len()`。
  4. **元组 (Tuple)**：
     - 元组的创建与只读特性（不可变性）。
     - 元组解包（Unpacking）。
- **实战练习**：
  - **任务 1：猜数字游戏**：预设一个数字，让用户循环输入猜测，提示“大了”或“小了”，猜对时退出循环。
  - **任务 2：成绩统计**：让用户依次输入 5 个学生的成绩存入列表，最后输出最高分、最低分以及平均分。

---

### 🔴 Day 3: 高级数据结构与字符串
- **今日目标**：掌握键值对映射（字典）和无序去重集合（集合），熟练进行字符串文本处理。
- **核心知识点**：
  1. **字典 (Dictionary)**：
     - 键值对的结构，键必须是不可变类型（通常是字符串或数字）。
     - 增加、删除、修改、查找键值对。
     - 常用方法：`keys()`, `values()`, `items()`, `get()`（安全获取值避免 KeyError）。
  2. **集合 (Set)**：
     - 集合的去重特性。
     - 集合运算：并集 (`|`)、交集 (`&`)、差集 (`-`)。
  3. **字符串操作**：
     - 常用方法：`strip()`, `split()`, `join()`, `replace()`, `lower()`, `upper()`, `startswith()`, `endswith()`。
- **实战练习**：
  - **任务 1：单词频率统计**：给定一段英文文本，将其分割成单词，并统计每个单词出现的次数，用字典保存并打印。
  - **任务 2：双列表去重复并求交集**：创建两个含有重复元素的列表，利用集合去除重复，并求出两个列表的共同元素（交集）。

---

### 🔴 Day 4: 函数与模块化
- **今日目标**：理解代码复用的核心——函数，学习参数传递规则与作用域，掌握模块的导入与创建。
- **核心知识点**：
  1. **定义函数**：`def` 关键字，返回值 `return`（默认返回 `None`）。
  2. **函数参数**：
     - 位置参数与关键字参数。
     - 默认参数（注意：默认参数必须放在非默认参数后面，且避免使用可变对象如空列表作为默认值）。
     - 可变参数 `*args`（元组）与 `**kwargs`（字典）。
  3. **变量作用域**：全局变量（`global`）与局部变量。
  4. **模块与包**：
     - 导入标准库：`import math`, `import random`, `from datetime import datetime`。
     - 编写自定义模块：在一个 `.py` 文件中定义函数，在另一个文件中 `import` 导入使用。
- **实战练习**：
  - **任务 1：简易计算器模块**：编写一个名为 `calculator.py` 的模块，包含加、减、乘、除四个函数（注意除数不能为0）。在 `main.py` 中导入并测试。
  - **任务 2：斐波那契数列生成器**：编写一个函数，接收参数 $N$，返回含有前 $N$ 个斐波那契数的列表。

---

### 🔴 Day 5: 文件操作与异常处理
- **今日目标**：掌握与外部系统交互的文件读写，学习如何编写健壮的容错代码，以及处理 JSON 数据。
- **核心知识点**：
  1. **文件读写 (File I/O)**：
     - 使用 `open(filename, mode)`，常用模式：`'r'` (读), `'w'` (覆盖写), `'a'` (追加写)。
     - 推荐使用 `with open(...) as f:` 自动关闭文件上下文管理器。
     - 读取方法：`read()`, `readline()`, `readlines()`。
  2. **异常处理 (Exception Handling)**：
     - 语法：`try...except...else...finally`。
     - 捕获指定异常（如 `ValueError`, `FileNotFoundError`, `ZeroDivisionError`）。
     - 主动抛出异常：`raise`。
  3. **JSON 序列化与反序列化**：
     - 导入 `json` 模块，使用 `json.dumps()`, `json.loads()`, `json.dump()`, `json.load()`。
- **实战练习**：
  - **任务 1：记账日志程序**：用户输入消费项目和金额，程序将其追加写入到 `expenses.txt` 中。再次启动时，程序能读取该文件并计算总支出。
  - **任务 2：配置读取器**：尝试读取一个 JSON 配置文件，如果文件不存在，捕获 `FileNotFoundError`，并自动创建一个默认的 JSON 配置写入磁盘。

### 🔴 Day 6: 面向对象编程 (OOP)
- **今日目标**：理解面向对象编程的思想，掌握类与对象的基本概念，学习三大特性：封装、继承与多态。
- **核心知识点**：
  1. **类 (Class) 与对象 (Object)**：
     - 使用 `class` 声明类。
     - 构造方法 `__init__(self, ...)` 初始化属性。
     - 实例方法与 `self` 的作用。
  2. **封装**：
     - 私有属性与私有方法：在名称前加双下划线（如 `self.__balance`），防止外部直接修改。
     - 提供 `getter` 和 `setter` 方法。
  3. **继承**：
     - 子类继承父类：`class Dog(Animal):`。
     - 方法重写 (Override) 与 `super()` 调用父类方法。
  4. **多态**：不同子类对象调用相同的方法名，表现出不同的行为。
- **实战练习**：
  - **任务 1：银行账户系统**：
    - 设计一个 `BankAccount` 类，包含 `owner` (开户人) 和 `__balance` (私有余额) 属性。
    - 提供 `deposit()` (存款), `withdraw()` (取款) 和 `get_balance()` (查询余额) 方法。确保取款时余额不足会打印警告或报错。
  - **任务 2：图书管理系统**：
    - 设计 `Book` 类（包含书名、作者、状态）和 `Library` 类（包含书单列表，提供添加图书、借阅图书、归还图书的方法）。

### 🔴 Day 7: Python 高级特性与综合实战
- **今日目标**：掌握 Python 高效优雅的高级特性，理解包管理，并完成一个能够运行的命令行应用。
- **核心知识点**：
  1. **推导式 (Comprehensions)**：
     - 列表推导式：`[x**2 for x in range(10) if x % 2 == 0]`。
     - 字典推导式。
  2. **匿名函数与高阶函数**：
     - `lambda` 表达式。
     - `map()`, `filter()` 的配合使用。
  3. **环境与包管理**：
     - 理解虚拟环境的作用：`python -m venv venv`。
     - 激活虚拟环境与使用 `pip install <package_name>` 安装第三方包。
- **🛠️ 终极实战项目：命令行待办事项 (To-Do CLI) 管理器**
  - **功能要求**：
    1. 允许用户添加任务、标记任务为已完成、查看任务列表、删除任务。
    2. 使用 **面向对象** 思想设计（可设计 `Task` 类和 `TodoList` 类）。
    3. 任务数据需在程序退出时自动保存为 JSON 文件，下次启动时自动加载。
    4. 对用户输入进行异常捕获，确保程序不会崩溃。

## 💡 学习建议与技巧

1. **动手实践 > 只看不写**：每学习一个概念，务必在编辑器中手打一遍代码。
2. **善用 Debug**：当程序不符合预期时，尝试在关键行打印 `print()` 或者利用 VS Code 的 Debug 调试功能单步跟踪。
3. **查阅官方文档**：遇到不熟悉的标准库函数，学会看 [Python 官方文档 (docs.python.org)](https://docs.python.org/zh-cn/3/)。
4. **代码规范**：从一开始就遵循 **PEP 8** 代码风格指南（比如：逗号后面加空格，函数之间空两行等）。
