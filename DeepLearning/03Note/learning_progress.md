# 深度学习学习进度

## 使用方法

- 学习前：查看本次目标和需要回答的问题。
- 学习中：记录不理解的概念、代码错误和实验现象。
- 学习后：不看笔记完成复述与自测。
- 复习时：优先处理“尚不能独立解释”的条目。
