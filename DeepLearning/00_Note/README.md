## 总体学习路线

### 模块一：建立机器学习知识地图

**目标**

- 分清 AI、机器学习和深度学习。
- 分清任务、学习方式、算法、模型、架构和框架。
- 理解监督学习、无监督学习、自监督学习和强化学习。

**完成标准**

- [ ] 能用自己的语言解释 AI、机器学习和深度学习的包含关系。
- [ ] 能判断 CNN、GPT、Transformer、PyTorch、Keras 分别属于哪一层。
- [ ] 能为一个现实问题判断它更接近分类、回归、聚类还是生成任务。

### 模块二：理解神经网络怎样学习

**目标**

- 理解特征、标签、参数和超参数。
- 理解前向传播、损失函数、梯度下降和反向传播。
- 理解训练集、验证集、测试集和过拟合。

**输出**

- 用 NumPy 或手算完成一个简单神经元的预测和参数更新。
- 使用 PyTorch 完成一个基础分类或回归任务。

**理论笔记**

- [神经网络如何学习：理论基础](./04_神经网络如何学习_理论.md)

### 模块三：CNN 与视觉模型

**目标**

- 理解局部连接、卷积核、参数共享、特征图和池化。
- 理解 CNN 为什么比全连接网络更适合图像。
- 认识 LeNet、AlexNet、VGG、ResNet 和 Vision Transformer 的关系。

### 模块四：RNN、LSTM 与序列建模

**目标**

- 理解序列、隐藏状态和循环计算。
- 理解梯度消失、长期依赖和门控记忆。
- 比较 RNN、LSTM 与 GRU。

### 模块五：Attention 与 Transformer

**目标**

- 从 Seq2Seq 的固定长度表示瓶颈理解 Attention。
- 理解 Self-Attention、Q/K/V、多头注意力和位置编码。
- 理解 Encoder、Decoder、BERT 与 GPT 的关系。

### 模块六：现代深度学习

**目标**

- 理解预训练、微调、Embedding 和大语言模型。
- 认识 VAE、GAN、Diffusion、ViT 和多模态模型。
- 使用 Hugging Face 加载并微调一个预训练模型。

## 推荐实践工具顺序

```text
少量 NumPy 手写
    ↓ 理解矩阵计算和反向传播
PyTorch
    ↓ 实现神经网络、CNN、LSTM 和 Transformer
Keras
    ↓ 比较高层 API 如何简化建模过程
Hugging Face
    ↓ 使用和微调成熟的预训练模型
```

## 每次学习的记录流程

1. **理解**：写下概念解决的问题和核心机制。
2. **编写**：完成最小可运行示例。
3. **验证**：记录运行结果、错误原因和修正方法。
4. **复述**：不用资料，用自己的语言解释知识点。
5. **提交**：只检查并提交本次新增或修改的学习文件。
