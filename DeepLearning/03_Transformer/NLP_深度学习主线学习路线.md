# Transformer 通用基础架构深入学习路线

> 主线：离散表示（One-hot）→ Embedding → RNN → LSTM → Seq2Seq → Attention → Self-Attention → Transformer

> 学习中心：理解 Transformer 的表示方式、信息流、数学机制、训练与推理，而不是把学习限定为解决 NLP 问题。

## 1. 路线定位

Transformer 是一种通用神经网络架构，也是许多基础模型的核心骨架。它最早在序列建模中成熟，但现在已广泛用于文本、图像、语音、时间序列、推荐系统、多模态、科学计算和机器人等方向。

需要准确区分两个概念：

- **Transformer**：一种由注意力、前馈网络、残差连接和归一化等组件构成的模型架构；
- **基础模型**：通常是在大规模数据上预训练、能够迁移到多种任务的模型，Transformer 是当前许多基础模型采用的核心架构。

因此，本路线使用文本和词向量作为最容易观察的入门载体，但不会把学习目标限制在 NLP。学习过程中始终追问：

1. 任意领域的数据如何被转换成统一的向量或 token 序列？
2. 模型如何表示元素之间的关系、位置和上下文？
3. Attention 与 Self-Attention 究竟完成了什么计算？
4. Transformer 为什么能够并行训练、扩展规模并迁移到不同领域？
5. 更换数据模态时，哪些组件保持不变，哪些组件必须重新设计？

## 2. 最终能力目标

完成路线后，应能够：

- 从张量、矩阵运算和信息流角度解释 Transformer；
- 独立推导 Embedding、Attention、Multi-Head Attention 和前馈网络的形状变化；
- 不调用现成 Transformer 模块，手写一个可训练的小型 Transformer；
- 解释 Encoder-only、Decoder-only 和 Encoder-Decoder 三类架构；
- 理解预训练、微调、提示学习和推理之间的关系；
- 将同一个 Transformer 主干迁移到至少两种不同数据模态；
- 分析模型的参数量、计算量、显存占用、训练稳定性和推理瓶颈；
- 阅读 Transformer 相关论文，并判断论文改变了输入表示、核心模块、训练目标还是推理方式。

## 3. 贯穿全程的通用视角

无论处理什么行业的数据，都将模型拆成下面五层：

```text
原始数据
  ↓
切分与序列化（token / patch / 时间窗 / 事件 / 状态）
  ↓
Embedding + 位置信息
  ↓
Transformer 主干
  ↓
任务头或生成头
  ↓
损失函数与训练目标
```

跨领域迁移时，Transformer 主干往往可以保持相似，主要变化发生在：

- 数据如何切分为基本单元；
- 基本单元如何映射成向量；
- 位置、时间、空间或结构信息如何注入；
- 使用哪一种 mask；
- 采用什么训练目标；
- 输出如何还原为领域需要的结果。

## 4. 学习方法与建议周期

建议用 **14～20 周**完成，每周学习 5 天、每天 1.5～2 小时。不要以“看完章节”为完成标准，而要以“能够推导、实现、验证和迁移”为标准。

每个模块遵循同一学习闭环：

> 建立直觉 → 明确张量含义 → 推导公式与形状 → 手写最小实现 → 用 PyTorch 验证 → 设计对照实验 → 总结可迁移规律

每次学习至少留下以下一种产出：

- 概念与公式笔记；
- 张量形状表或信息流图；
- 可运行的最小代码；
- 对照实验记录；
- 面向其他领域的迁移说明；
- 对错误、现象和结论的复盘。

## 7. 模块 ①：离散表示与 One-hot

### 学习目标

- 理解离散类别、索引、词表或符号表；
- 理解 One-hot 是通用类别编码，不只用于单词；
- 理解稀疏表示为什么需要进一步映射到连续空间。

### 核心内容

- 类别到索引的映射；
- One-hot、稀疏性和正交性；
- 标称类别与数值大小之间的区别；
- 未知类别、填充类别和特殊标记；
- One-hot 乘权重矩阵与直接查表的等价性。

### 跨领域观察

- 文本：单词、子词或字符编号；
- 推荐系统：用户、商品、行为类型编号；
- 表格数据：地区、设备类型或故障类型编号；
- 图与科学计算：节点类型、原子类型或事件类型编号；
- 强化学习：离散动作编号。

## 8. 模块 ②：Embedding——Transformer 的通用输入接口

### 学习目标

- 将 Word Embedding 理解为通用 Embedding 的一个实例；
- 理解离散索引、连续特征和高维数据如何统一到 `d_model`；
- 掌握 Embedding 的参数、梯度和张量形状。

### 核心内容

- Embedding 矩阵：`类别数量 × 表示维度`；
- 查表、线性投影和可学习表示；
- 相似度、向量空间和训练目标；
- 标量、向量、矩阵和高阶张量；
- batch、sequence、feature 三个核心轴；
- 静态表示与上下文表示；
- 离散 Embedding、连续值投影、Patch Embedding；
- 位置、时间、空间、模态和类型 Embedding。

### 统一形状

Transformer 主干通常希望接收：

```text
[batch_size, sequence_length, d_model]
```

不同领域只是产生这个张量的方式不同：

| 领域 | 序列元素 | 输入映射方式 |
| --- | --- | --- |
| 文本 | token / subword | Embedding 查表 |
| 图像 | patch | 展平后线性投影或卷积投影 |
| 时间序列 | 时间点或时间窗 | 连续特征线性投影 |
| 语音 | 声学帧或局部片段 | 特征提取器 + 线性投影 |
| 推荐 | 用户、商品、行为事件 | 多类 Embedding 组合 |
| 机器人 | 状态、观测、动作 | 连续投影或离散 Embedding |
| 多模态 | 各模态 token | 各自编码后对齐到同一 `d_model` |

- [ ] 用线性层把连续时间序列从 `input_dim` 投影到 `d_model`
- [ ] 把小图像切成 patch，并投影为 patch token
- [ ] 将文本、时间序列和图像 token 统一为三维张量

### 完成标准

- [ ] 能解释 Embedding 矩阵每一行的含义
- [ ] 能解释查表与线性投影的区别和共同目标

## 9. 模块 ③：RNN——序列状态与循环依赖

- 展开计算图与 BPTT；
- 梯度消失、梯度爆炸和梯度裁剪；

## 12. 模块 ⑥：Attention——可微的信息检索与聚合

### 学习目标

### 核心内容

- Value：匹配后真正被聚合的内容；
- 打分、缩放、mask、softmax 和加权求和；
- Additive Attention 与 Dot-Product Attention；
- Cross-Attention；
- 注意力权重可视化的价值与局限。

## 13. 模块 ⑦：Self-Attention——序列内部的全局关系建模

### 学习目标

- 掌握缩放点积 Self-Attention；
- 理解位置编码、mask 和多头机制的必要性；
- 能从张量和复杂度角度分析其优势与代价。

### 核心内容

- 同一输入生成 Q、K、V；
- `Attention(Q,K,V) = softmax(QK^T / sqrt(d_k))V`；
- padding mask、causal mask 和结构 mask；
- 序列长度维上的两两关系矩阵；
- 位置排列信息与位置编码；
- 多头子空间；
- `O(n²)` 时间与空间复杂度；
- Self-Attention 与卷积、循环的归纳偏置差异。

### 实践任务

- [ ] 实现多头拆分、并行计算和拼接
- [ ] 对比 RNN、卷积和 Self-Attention 的依赖路径

- [ ] 能说明 causal mask 如何阻止未来信息泄露

## 14. 模块 ⑧：Transformer——完整架构、训练与推理

### 学习目标

- 从基础组件组装完整 Transformer；
- 理解三类主流架构及其训练目标；
- 掌握训练稳定性、推理流程和跨领域迁移方法。

### 14.1 架构组件

- 输入投影与位置编码；
- Multi-Head Attention；
- Position-wise Feed-Forward Network；
- Residual Connection；
- LayerNorm、Pre-Norm 与 Post-Norm；
- Dropout；
- Encoder Self-Attention；
- Decoder Masked Self-Attention；
- Encoder-Decoder Cross-Attention；
- 输出头与权重共享。

### 14.2 三类结构

| 架构 | 信息可见范围 | 常见训练思想 | 适合的问题形式 |
| --- | --- | --- | --- |
| Encoder-only | 通常双向读取输入 | 掩码恢复、表征学习、对比学习 | 理解、分类、检索、编码 |
| Decoder-only | 只能读取当前位置之前 | 自回归预测下一个 token | 生成、决策、序列建模 |
| Encoder-Decoder | Encoder 双向，Decoder 因果，并通过 Cross-Attention 连接 | 条件生成、去噪重建 | 输入序列到输出序列 |

### 14.3 训练与稳定性

- 参数初始化；
- AdamW、学习率预热和调度；
- 梯度裁剪和梯度累积；
- batch、序列长度与显存；
- 混合精度；
- 训练集、验证集与过拟合；
- 消融实验和随机种子；
- 数据规模、模型规模和计算资源之间的关系。

### 14.4 推理与效率

- 自回归生成；
- greedy、beam、temperature、top-k、top-p；
- KV Cache；
- 训练并行与生成串行的区别；
- 参数量、FLOPs、吞吐、延迟和显存；
- 长序列的二次复杂度；
- 稀疏注意力、线性注意力、局部窗口等优化方向。

## 15. 跨领域迁移地图

深入理解 Transformer 的关键，不是记住所有行业模型名称，而是识别同一架构在不同数据上的变化位置。

| 方向 | token 或序列单元 | 位置/结构信息 | 常见输出 |
| --- | --- | --- | --- |
| 文本 | 字符、词、子词 | 一维顺序位置 | 类别、向量、下一 token |
| 计算机视觉 | 图像 patch、区域、像素 | 二维空间位置 | 类别、检测框、分割或图像 token |
| 语音 | 音频帧、声学片段 | 时间位置 | 声学表示、文字、音频单元 |
| 时间序列 | 时间点、时间窗、变量 token | 时间戳、周期、变量身份 | 预测值、异常、状态类别 |
| 推荐系统 | 用户、商品、行为事件 | 行为顺序、时间间隔 | 下一物品、排序得分 |
| 图与分子 | 节点、边、原子、残基 | 邻接关系、空间结构 | 性质、结构、类别 |
| 机器人与控制 | 状态、观测、动作、回报 | 轨迹时间与环境状态 | 动作或未来轨迹 |
| 多模态 | 文本、图像、音频等 token | 模态类型与各自位置 | 跨模态表示或生成结果 |

面对新行业时，使用以下六问：

1. 什么是最合理的 token？
2. 输入怎样映射到统一的 `d_model`？
3. 顺序、空间、时间或图结构怎样编码？
4. 哪些元素之间应该允许互相注意？
5. 训练目标如何反映业务或科学目标？
6. 输出头如何将隐藏表示还原成可用结果？

## 17. 当前学习重点：Embedding 与张量

当前阶段先学习 Word Embedding 是合理的，但需要使用更宽的视角：

```text

    是
```

3. 理解 Embedding 查表与 One-hot 矩阵乘法等价；
4. 理解连续特征为什么通常使用线性投影而不是查表；

## 23. 主线结论

这条路线不是为了逐个掌握 NLP 模型，而是通过历史演进理解 Transformer 为什么成为通用架构：

1. **One-hot** 建立离散对象与索引表示，但不包含相似关系；
2. **Embedding** 将不同对象映射到连续表示空间，并成为各模态进入模型的接口；
3. **RNN** 引入状态和顺序依赖，但计算串行且长依赖困难；
4. **LSTM** 使用门控记忆缓解长依赖，但仍受循环计算限制；
5. **Seq2Seq** 建立通用的输入—输出序列框架，但固定上下文形成瓶颈；
6. **Attention** 提供按需检索和聚合信息的机制；
7. **Self-Attention** 让所有序列元素直接建立关系，并支持并行训练；
8. **Transformer** 把注意力、位置、前馈网络、残差和归一化组合成可堆叠、可扩展、可迁移的通用主干。

最终要形成的思维方式是：

> 面对一个新领域，先研究如何把对象表示为 token 和向量，再研究关系、位置、信息可见范围、训练目标和输出形式；Transformer 主干只是这套系统的核心计算结构。
